# Where to apply (access-first list)

The goal is interviews, not prestige. Apply in this order.

## 1. Managed service providers (MSPs) — highest conversion

You will touch monitoring, ticketing, DNS, backups and customer triage on day one. It is the closest thing to the job this project simulates.

Search: `NOC technician`, `NOC analyst`, `IT support engineer`, `monitoring analyst`, `managed services engineer`, `systems administrator intern`.

## 2. ISPs, colocation and data centers

Real NOC shifts, real tickets, real escalation. Look for `NOC technician`, `network operations analyst`, `data center technician`, `network technician`.

## 3. Cloud support / cloud operations

The accessible door into cloud: `Cloud Support Associate` (AWS), `Cloud Support Engineer`, `Cloud Operations Analyst`, `Technical Support Engineer (cloud)`. These value the dependency-chain reasoning in this project more than LeetCode.

## 4. Banks, hospitals, universities, retail

`NOC analyst`, `infrastructure analyst`, `IT operations intern`, `network intern`. Less glamorous, more accessible, and often remote-friendly.

## 5. Remote-first startups

`Infrastructure intern`, `platform intern`, `IT operations`. Fewer structured programs, but faster decisions. Check that they hire internationally.

## Weekly cadence

- 10–15 applications per week, tailored first line each time.
- Follow up after 7 days, once, with a one-paragraph note and the repo link.
- Track every application in [`tracker.csv`](tracker.csv).
- Rejections are data: note the stage where you stopped.

## What to attach

1. One-page resume (use the bullets in [`../resume-bullets.md`](../resume-bullets.md)).
2. Link to the repository, with the 3-minute video at the top.
3. A one-page PDF "Operations Report": uptime, incidents, time-to-ticket, open risks.

## Red flags to avoid

- "Remote" postings that require US work authorization. Read the fine print before spending an hour on the application.
- Unpaid "trial projects" longer than a few hours.
- Roles that are 90% phone support with no infrastructure exposure, unless you need the first job.
