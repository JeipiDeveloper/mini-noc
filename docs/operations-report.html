What changed as a result

  • Reduced Alertmanager group_interval from 2 min to 30 s after the first resolved notification arrived late.
  • Added inhibition so a DNS failure suppresses WebDown and ApiDegraded; one cause, one page.
  • Documented the alert-window trade-off in ADR 004, with the measured detection times.
  • Added a client-perspective probe and a disk-capacity alert to the backlog.

Open risks

  • Single host: no HA, no failover. A host failure is a total outage.
  • Single resolver: CoreDNS is a shared point of failure.
  • No database backup job yet; volume loss means data loss.
  • No dynamic routing (BGP/OSPF) in scope yet.

Evidence and reproducibility
